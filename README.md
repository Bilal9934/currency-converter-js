# 💱 Currency Converter Web Application

A responsive and interactive **Currency Converter** built with **HTML, CSS, and JavaScript**.
The application fetches **live exchange rates** from a currency exchange API, 
allowing users to convert between multiple currencies accurately in real time through a clean and intuitive interface.

---

## 🚀 Features

- 🌍 Convert between multiple international currencies
- 📡 Fetches live exchange rates using a Currency Exchange API
- ⚡ Instant and accurate currency conversion
- 🔄 Dynamic updates without page refresh
- 📱 Fully responsive design for desktop and mobile devices
- 🎨 Clean, modern, and user-friendly interface
- 🖥️ Interactive DOM manipulation with JavaScript

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & Responsive Design
- **JavaScript (ES6)** – Application Logic
- **Exchange Rate API** – Live currency exchange data

---

## 💡 How It Works

1. Enter the amount to convert.
2. Select the source currency.
3. Select the target currency.
4. Click the **Convert** button.
5. The application requests the latest exchange rates from the API.
6. The converted amount is displayed instantly.

---

## 🌐 API

This project uses a **Currency Exchange Rate API** to retrieve the latest exchange rates, ensuring accurate and up-to-date currency conversions.
